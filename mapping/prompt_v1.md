# Rubrica v1 — autoria semântica na sessão

Fonte exclusiva: sample_packet.json, seis itens, matriz completa e duas ementas nela incorporadas. Não consultar holdout, output, outras bases, API ou rede. Amostra não representativa; nenhuma métrica de acurácia ou confiança calibrada.

1. Ler a demanda efetiva do enunciado e alternativas; descrever o que é necessário fazer para acertar. Gabarito é dado preservado, não validação pedagógica.
2. Propor par OC→COMP somente quando a operação exigida dá evidência de um aspecto explícito da competência, apoiado pela matriz e ementa. Conhecimento pré-requisito e coincidência temática não bastam. Não declarar competência integralmente medida.
3. Citar literalmente campo do item, JSON pointer da matriz e arquivo/linhas da ementa. Habilidades esclarecem aspectos, não são novos vínculos.
4. Se faltar contexto, escopo curricular ou demanda cognitiva suficiente, abster com links vazios e motivo. Registrar candidatos rejeitados separadamente. Não completar textos ou corrigir gabaritos.
5. Ambiguidades não impeditivas ficam pendentes; nenhum vínculo equivale a aprovação humana. Status: suggested ou abstained; human_review: pending em todos os casos.
6. Separar regras estruturais: hipótese provisória do manager conta nós OC+COMP únicos (1–3); habilidades ficam fora. Reportar pares e OCs. Abstenções: not_applicable. COMP permitida pelo OC é interpretação conservadora provisória. Violações pedem revisão e jamais truncam sugestões.

Proveniência: session_agent_authored, IA real desta sessão; não simulação, não API GPT-5 mini. Verificador determinístico valida integridade formal e citações, nunca mérito pedagógico. Integração API não executada.
